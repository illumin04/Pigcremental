# Pigcremental

A cute incremental game about pigs, built with Unity. Centered around the famous google emoji (Noto Color Emoji 17.0):pig.

## Vision

Pigcremental is a lightweight incremental game focused on:
- simple but polished UI
- satisfying number growth
- cute pig-themed progression
- low art complexity
- a complete playable demo within a limited development schedule

## Core Loop

1. Feed pigs using items
2. Increase pig population
3. Unlock passive production, and pigs can work to get the items you need to feed pigs.
4. Purchase upgrades, so pigs can get more items while working.
5. Unlock new systems, more ways to increase the production.
6. Progress into larger-scale pig civilization.
7. Entercounter random events with trigger points, that have random impact on the civilization.

## Tech Stack

- Unity
- C#
- TextMeshPro
- 2D UI
- Local save system
- PNG / vector-style UI assets

## Art Direction

- Cute, but not overly cartoonish
- Bright casual-game visuals
- Rounded UI panels
- Poppins-based typography
- Pig-themed icons and simple illustrations
